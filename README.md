# 🏠 Missão Casa

Protótipo de app gamificado para a rotina da família: missões do dia, revezamento automático (quem toma banho primeiro, quem tira o lixo…), placar da semana com prêmio e painel dos pais.

- Abre no navegador do celular; dá para "Adicionar à tela inicial".
- Por enquanto os dados ficam salvos no próprio aparelho. Próximo passo: Firebase para sincronizar entre celulares.
- Senha padrão do painel dos pais: `1234` (troque no painel).

Ideia de Maitê e Maya.
